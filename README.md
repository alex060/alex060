### [PokeTokenBar para Windows](https://github.com/alex060/PokeTokenBar-Windows)
Aplicación de escritorio en **Python y PyQt6** que convierte el consumo local de tokens de herramientas de IA en la progresión de un compañero Pokémon. Incluye lectura incremental de JSONL y SQLite, sistema de evoluciones, variantes shiny y persistencia local.

### [usersApp](https://github.com/alex060/usersApp)
Aplicación de usuarios desarrollada con **Ionic, Angular y TypeScript**, estructurada con modelo, servicio y vista. Está preparada para despliegue web y cuenta con una [demo en Vercel](https://users-app-brown.vercel.app/).
